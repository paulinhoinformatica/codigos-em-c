INSTRUÇÕES À PROGRAMAÇÃO EM C

O que é a Linguagem C?

A linguagem C é uma das linguagens de programação mais utilizadas no mundo. Ela é rápida, eficiente e serviu de base para diversas outras linguagens, como C++, C# e Java.

Estrutura Básica

#include <stdio.h>

int main()
{
    printf("Olá Mundo!");

    return 0;
}

#include <stdio.h> - Biblioteca responsável pelas funções de entrada e saída de dados.

int main() - Função principal do programa. Todo programa em C começa sua execução por ela.

printf() - Função utilizada para exibir mensagens na tela.

return 0; - Indica que o programa foi encerrado corretamente.

Variáveis

Variáveis armazenam informações na memória para serem utilizadas durante a execução do programa. 

int idade = 18;
float altura = 1.75;
char letra = 'A';

int - Armazena números inteiros.

float - Armazena números com casas decimais.

char - Armazena um único caractere.

Tipos de Dados

Tipo Descrição
int Números inteiros
float Números decimais
char Caracteres
double Maior precisão decimal

Entrada de Dados

int idade;

printf("Digite sua idade: ");
scanf("%d", &idade);

scanf() - Função utilizada para receber informações digitadas pelo usuário.

%d - Formato utilizado para números inteiros.

&idade - Indica o endereço da variável onde o valor digitado será armazenado.

Estruturas Condicionais

if(idade >= 18)
{
    printf("Maior de idade");
}
else
{
    printf("Menor de idade");
}

if - Executa um bloco de código se a condição for verdadeira.

else - Executa um bloco de código se a condição for falsa.

>= - Operador que significa "maior ou igual".

Estruturas de Repetição

For

for(int i = 1; i <= 5; i++)
{
    printf("%d", i);
}

O for é utilizado quando sabemos quantas vezes uma repetição será executada.

int i = 1 - Valor inicial.

i <= 5 - Condição para continuar repetindo.

i++ - Incrementa 1 ao valor da variável.

While

int i = 1;

while(i <= 5)
{
    printf("%d", i);
    i++;
}

O while executa o bloco de código enquanto a condição for verdadeira.

Funções

int soma(int a, int b)
{
    return a + b;
}

Funções são blocos de código criados para realizar tarefas específicas.

return retorna um valor para quem chamou a função.

Vetores

int numeros[5] = {10, 20, 30, 40, 50};

Vetores permitem armazenar vários valores do mesmo tipo em uma única variável.

Neste exemplo, o vetor possui 5 posições.

Comentários

// Comentário de uma linha

/*
Comentário
de várias linhas
*/

Comentários servem para explicar o código e não são executados pelo compilador.

// cria um comentário de uma linha.

/* */ cria comentários com várias linhas.





INSTRUÇÕES À PROGRAMAÇÃO EM PYTHON

O que é Python?

Python é uma linguagem de programação de alto nível, conhecida por sua simplicidade e facilidade de aprendizado. Ela é muito utilizada em áreas como desenvolvimento web, automação, inteligência artificial, análise de dados e criação de aplicativos.

Estrutura Básica

print("Olá Mundo!")

print() - Função utilizada para exibir mensagens na tela.

Diferente da linguagem C, Python não necessita da função main() nem de bibliotecas para exibir mensagens simples.

Variáveis

Variáveis são utilizadas para armazenar informações na memória. 

idade = 18
altura = 1.75
nome = "João"

Em Python não é necessário informar o tipo da variável.

O próprio Python identifica automaticamente se o valor é um número, texto ou decimal.

Tipos de Dados

Tipo Descrição
int Números inteiros
float Números decimais
str Textos
bool Verdadeiro ou falso

Entrada de Dados

nome = input("Digite seu nome: ")

input() - Função utilizada para receber informações digitadas pelo usuário.

O valor digitado será armazenado na variável nome.

Estruturas Condicionais

idade = 18

if idade >= 18:
    print("Maior de idade")
else:
    print("Menor de idade")

if - Executa um bloco de código caso a condição seja verdadeira.

else - Executa um bloco de código caso a condição seja falsa.

Em Python, os blocos são definidos pela indentação e não por chaves.

Estruturas de Repetição

For

for i in range(5):
    print(i)

O for é utilizado para repetir uma ação um determinado número de vezes.

range(5) gera números de 0 até 4.

While

i = 0

while i < 5:
    print(i)
    i += 1

O while executa o bloco enquanto a condição for verdadeira.

Funções

def soma(a, b):
    return a + b

def é a palavra utilizada para criar funções em Python.

return retorna um valor para quem chamou a função.

Listas

numeros = [10, 20, 30, 40, 50]

As listas permitem armazenar vários valores em uma única variável.

Cada elemento possui uma posição, começando pelo índice 0.

Comentários

# Comentário de uma linha

"""
Comentário
de várias linhas
"""

Comentários servem para explicar o código e facilitar sua manutenção.

# cria um comentário de uma linha.





INSTRUÇÕES À PROGRAMAÇÃO EM JAVA

O que é Java?

Java é uma linguagem de programação orientada a objetos muito utilizada no desenvolvimento de aplicativos, sistemas empresariais, aplicações web e aplicativos Android. Sua principal característica é a portabilidade, permitindo que um programa seja executado em diferentes sistemas operacionais.

Estrutura Básica

public class Main {

    public static void main(String[] args) {

        System.out.println("Olá Mundo!");

    }

}

public class Main - Define uma classe chamada Main.

main() - Método principal do programa. A execução começa por ele.

System.out.println() - Exibe mensagens na tela.

{ } - Delimitam o início e o fim de blocos de código.

Variáveis

Variáveis armazenam informações que podem ser utilizadas durante a execução do programa. 

int idade = 18;
double altura = 1.75;
String nome = "João";
char letra = 'A';

int - Armazena números inteiros.

double - Armazena números decimais.

String - Armazena textos.

char - Armazena um único caractere.

Tipos de Dados

Tipo Descrição
int Números inteiros
double Números decimais
String Textos
char Caracteres
boolean Verdadeiro ou falso

Entrada de Dados

import java.util.Scanner;

Scanner entrada = new Scanner(System.in);

System.out.print("Digite seu nome: ");
String nome = entrada.nextLine();

Scanner - Classe utilizada para receber dados do usuário.

nextLine() - Lê uma linha de texto digitada pelo usuário.

Estruturas Condicionais

if(idade >= 18){
    System.out.println("Maior de idade");
}
else{
    System.out.println("Menor de idade");
}

if - Executa um bloco de código quando a condição é verdadeira.

else - Executa um bloco quando a condição é falsa.

>= - Operador que significa "maior ou igual".

Estruturas de Repetição

For

for(int i = 1; i <= 5; i++){
    System.out.println(i);
}

O for é utilizado quando sabemos quantas vezes uma repetição deve ocorrer.

i++ incrementa 1 ao valor da variável.

While

int i = 1;

while(i <= 5){
    System.out.println(i);
    i++;
}

O while executa um bloco de código enquanto a condição for verdadeira.

Métodos

public static int soma(int a, int b){
    return a + b;
}

Métodos são blocos de código criados para executar tarefas específicas.

return retorna um valor para quem chamou o método.

Vetores

int[] numeros = {10, 20, 30, 40, 50};

Vetores permitem armazenar vários valores do mesmo tipo.

Cada posição do vetor possui um índice, começando em 0.

Comentários

// Comentário de uma linha

/*
Comentário
de várias linhas
*/

Comentários servem para explicar o código e não são executados pelo compilador.
